# FullHub

Корпоративный портал компании с авторизацией администратора и сотрудников.

## Реализовано

- Вход в систему по логину (телефон) и паролю.
- Роли:
  - **Администратор**: управление сотрудниками, сменами и финансами.
  - **Сотрудник**: личный кабинет с профилем, своими сменами и сводкой за месяц.
- Блок **Сотрудники**:
  - создание сотрудников (ФИО, должность, трудоустройство, форма оплаты, ставка/оклад, отдел, телефон, пароль);
  - редактирование/удаление сотрудников в таблице;
  - редактируемые справочники должностей, форм оплаты и отделов.
- Блок **Смены**:
  - интерактивный календарь;
  - назначение смен на дату;
  - поддержка сдельной, часовой и окладной оплаты;
  - цветовая маркировка по должностям.
- Блок **Финансы**:
  - фильтр по месяцу и отделу;
  - блок «рабочих дней в месяце» для расчета ставки по окладу (оклад / рабочие дни / 9 часов);
  - расчет начислений, НДФЛ, отдельный учет премий и штрафов, выплачено и остатка;
  - выплаты с типом `advance`, `salary` или `custom` (выплаты вне графика);
  - учет переработок для оклада: НДФЛ удерживается только в пределах оклада.

## Демо-доступ

- Администратор: `79990000000` / `admin123`
- Сотрудник: `79990000001` / `user123`

## Локальный запуск

```bash
python3 -m http.server 4173
```

Открыть: <http://localhost:4173>
