# FullHub

Корпоративный портал с ролями администратора и сотрудника.
Приложение работает полностью на клиенте (`HTML/CSS/JS`) и хранит данные в `localStorage`.

## Что реализовано сейчас

### 1) Авторизация и роли
- Вход по телефону (логину) и паролю.
- Роли:
  - **Администратор** — доступ к разделам «Сотрудники», «Смены Самара», «Смены Тольятти», «Финансы».
  - **Сотрудник** — личный кабинет с KPI, сменами и историей финансовых операций.
- Кнопка **«Сбросить локальные данные»** на экране входа очищает хранилище и загружает демо-данные.

---

### 2) Раздел «Сотрудники»
- Создание сотрудника в раскрывающейся форме (`+ Добавить сотрудника`).
- Поля сотрудника включают: ФИО, должность, трудоустройство, форма оплаты, график, ставка/оклад, отдел, дата рождения, телефон, пароль.
- Таблица сотрудников с inline-редактированием и удалением.
- Фильтры по поиску, отделу и должности.
- **Справочники** (должности/формы оплаты/отделы/графики):
  - режим редактирования через иконку **⚙️**;
  - удаление значений через маленькие красные крестики;
  - сохранение через **💾**.
- Карточка напоминаний о ближайших днях рождения сотрудников (до 30 дней).

---

### 3) Раздел «Смены»

#### Смены Самара
- Разделён на **3 отдельных блока**:
  1. Смены отдела логистики
  2. Смены отдела упаковки
  3. Смены водителей
- Каждый блок имеет:
  - кнопку **«открыть / скрыть»**;
  - собственный календарь;
  - собственную выбранную дату;
  - собственную форму добавления смены;
  - собственную таблицу смен на выбранную дату.
- Ограничение сотрудников по отделам:
  - логистика → только `Склад Самара`;
  - упаковка → только `Отдел Упаковки`;
  - водители → только `Водители`.

#### Смены Тольятти
- Отдельный раскрывающийся блок (кнопка **«открыть / скрыть»**) со своим календарём и формой смен.
- В смены можно добавлять только сотрудников отдела `Склад Тольятти`.

#### Дополнительно по сменам
- Поддержка форм оплаты: сдельная / часовая / оклад.
- Для сдельной оплаты — ввод суммы за смену; время начала/конца отключается.
- Цветовые чипы сотрудников по должностям в календаре.
- Автозаполнение смен по графику:
  - `5/2 (с понедельника по пятницу)` — смены `09:00–18:00` в рабочие дни;
  - `5/2 (со вторника по субботу)` — смены `09:00–18:00` в рабочие дни;
  - `5/2 (с понедельника по пятницу - свободный)` — смены создаются без времени (админ задаёт вручную или через QR-отметку);
  - `подработка` — автоматическое планирование не выполняется.

---

### 4) QR-отметка прихода/ухода
- В админке на странице «Сотрудники» есть карточка с **QR-кодом на текущий день**.
- В кабинете сотрудника есть кнопка **«Сканировать QR-код»**:
  - 1-й скан — фиксирует начало смены;
  - 2-й скан — фиксирует окончание смены;
  - повторные сканы после закрытия — только информируют, что смена уже закрыта.
- Если сотрудник пришёл **раньше 09:00**, в график/расчёт начало ставится с **09:00**.
- При отсутствии доступа к камере доступен fallback на ручной ввод токена.
- Для графика `подработка`: если смена на сегодня не назначена, при первом успешном скане QR она создаётся автоматически.

---

### 5) Раздел «Финансы»
- Фильтры:
  - месяц;
  - период `с / по`;
  - отдел;
  - сотрудник.
- Отдельная карточка **«Рабочие дни по месяцам»**:
  - переключение **⚙️ / 💾**;
  - наглядный список месяцев и количества рабочих дней;
  - используется в расчетах для оклада.
- Таблица финансов включает ФИО (фамилия, имя, отчество), отдел, должность и расчётные показатели (начислено, НДФЛ, премии, штрафы, к выплате, выплачено, остаток и т.д.).
- Новый сценарий действий:
  - выбор сотрудников чекбоксами в таблице;
  - кнопка **«Выбрать все / Снять всё»**;
  - автоматически показывается блок действий:
    - для одного сотрудника — персональное действие;
    - для нескольких — массовое действие;
  - поддержаны операции: **Выплата / Премия / Штраф**;
  - после «Выполнить» выбор очищается, блок действий скрывается.
- По двойному клику на строку таблицы открывается история сотрудника.
- Таблица визуально улучшена: hover-подсветка строк, аккуратный скролл внутри блока, без «вылезания» за макет.

---

### 6) Личный кабинет сотрудника
- Профиль и ключевые показатели за месяц:
  - количество смен;
  - часы;
  - начислено / НДФЛ / премии / штрафы / выплачено / остаток;
  - ближайшая плановая выплата;
  - сегодняшняя и следующая смена.
- История начислений/списаний.
- Список смен за месяц.

## Демо-доступ
- Администратор: `79990000000` / `admin123`
- Сотрудник: `79990000001` / `user123`

## Локальный запуск

```bash
python3 -m http.server 4173
```

Открыть: <http://localhost:4173>

1. На экране входа нажмите **«Сбросить локальные данные»**.
2. Убедитесь, что версия на экране входа: `2026.02.27-v4`.
3. Сделайте принудительное обновление страницы (`Ctrl+F5`).
