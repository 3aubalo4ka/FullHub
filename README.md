# FullHub

Корпоративный портал компании с авторизацией администратора и сотрудников.

## Реализовано

- Вход в систему по логину (телефон) и паролю.
- Роли:
  - **Администратор**: управление сотрудниками, сменами и финансами.
  - **Сотрудник**: личный кабинет с профилем, своими сменами и сводкой за месяц (начислено/выплачено/к выплате).
- Блок **Сотрудники**:
  - создание сотрудников (ФИО, должность, форма оплаты, ставка, отдел, телефон, пароль);
  - редактирование/удаление сотрудников в таблице;
  - редактируемые справочники должностей, форм оплаты и отделов.
- Блок **Смены**:
  - интерактивный календарь;
  - назначение смен на дату;
  - поддержка часовой и сдельной оплаты;
  - цветовая маркировка по должностям.
- Блок **Финансы**:
  - фильтр по датам и отделу;
  - расчёт смен, часов и зарплаты;
  - кнопка «Выплатить» по каждому сотруднику;
  - отображение «зарплата / выплачено / осталось» в выгрузке.

## Демо-доступ

- Администратор: `79990000000` / `admin123`
- Сотрудник: `79990000001` / `user123`

## Локальный запуск

```bash
python3 -m http.server 4173
```

Открыть: <http://localhost:4173>
